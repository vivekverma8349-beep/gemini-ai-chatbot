# Gemini AI Chatbot

A simple AI chatbot built using Node.js, Express, and Google Gemini API.

## Features

- Gemini AI integration
- Modern chatbot UI
- Real-time messaging
- Express backend
- Responsive design

---

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Gemini API

---

## Installation

```bash
npm install
```

Create `.env`

```env
GEMINI_API_KEY=your_api_key
```

Run server:

```bash
node server.js
```

Open:

```txt
http://localhost:5000
```
